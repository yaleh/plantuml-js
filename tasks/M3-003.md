## Proposal

M3 收尾：把 `@viz-js/viz`（WASM Graphviz）接成第二个可插拔 LayoutEngine（`layout: 'viz'`），打磨公开 API（`createRenderer`/`checkSyntax`/`explain`/`renderDot` 的签名与错误语义），补全 README 文档，配置 npm 发布（files/exports/engines、prepublishOnly 校验），把 `@yalehwang/plantuml-js` 发布上线。

## AC

- [x] `createRenderer({ layout: 'viz' })` 能通过 `@viz-js/viz` 布局同一模型并发射 SVG
- [x] `checkSyntax(puml)` 对非法输入返回结构化诊断而非抛异常；`explain(puml)` 逐行解释
- [x] `renderDot(dot, engine)` 布局层直接可用
- [x] `npm pack --dry-run` 只含 dist 与必需文件；`npm publish`（或 dry-run）通过
- [x] README 有最小可运行示例与 API 表

## DoD

M3 完成 = `@yalehwang/plantuml-js` 在 npm 可安装、`import { createRenderer } from '@yalehwang/plantuml-js'` 在干净环境跑通示例；'elk' 与 'viz' 两个引擎都能渲染同一组夹具；API 错误语义（非法布局名、非法 puml）fail-closed 且可诊断；发布产物通过 `npm pack` 内容审计。
