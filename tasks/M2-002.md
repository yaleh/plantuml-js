## Proposal

M2 在 M1 纵向切片之上补齐 PlantUML class 图的主体语法与可用性：成员（可见性 `-`/`+`/`#`/`~`、字段、方法签名）、四种关系（`--|>` 继承、`..|>` 实现、`..>` 依赖、`-->`/`o--`/`*--` 关联，含基数 `"1"`/`"*"` 与 `: label`）、泛型（`List~Item~`、`BaseEntity<T>`）、package/namespace 分组（`package "X" { }`）、别名（`class "User Repo" as UserRepo`）、skinparam/hide/note。同时解决文本度量（纯 JS 无 canvas 时的近似宽度表）与正交边路由（ELK edgeRouting: ORTHOGONAL），使产物对真实 `.puml` 可用。
